# Dataset registry

Both bundled datasets are synthetic and generated with deterministic code for this repository. They contain no personal or confidential records.

## Customer Conversion v1.0.0

Binary classification with numerical and categorical product-usage attributes. Target: `converted`.

## Revenue Forecast v1.0.0

Regression with marketing, web-traffic, and categorical seasonal attributes. Target: `revenue`.

The exact SHA-256 fingerprints and shapes are stored in `public/datasets/catalog.json`.
