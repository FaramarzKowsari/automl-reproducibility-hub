# AutoML Reproducibility Hub v1.0.0

Initial public research-software release.

- Static Reference and Full Browser execution modes.
- Versioned synthetic classification and regression datasets.

- DuckDB-WASM dataset profiling.

- Logistic, linear, and random-forest pipelines.
- Compact AutoML candidate comparison.
- Exportable experiment manifests and Python skeletons.
- Local experiment history.
- CI, GitHub Pages, citation, Zenodo, security, and contribution metadata.
