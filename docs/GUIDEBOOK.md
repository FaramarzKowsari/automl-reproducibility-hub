# Inside AutoML Reproducibility Hub

**Subtitle:** A Visual Guide to Reproducible Browser-Based Machine Learning  
**Author:** Faramarz Kowsari  
**Format:** 10-page A4 infographic PDF  
**Language:** English

## Purpose

This is the official visual guidebook for the AutoML Reproducibility Hub repository. It explains the project's scientific purpose, browser-first architecture, S + F execution modes, experiment lifecycle, dataset identity, manifest generation, model evaluation, privacy boundaries, deployment workflow, and publication readiness.
