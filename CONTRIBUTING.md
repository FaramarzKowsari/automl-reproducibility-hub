# Contributing

1. Fork the repository and create a focused branch.
2. Preserve the distinction between Static reference results and Full executed results.
3. Add or update tests for deterministic helper functions.
4. Run `npm run check` before opening a pull request.
5. Do not commit real personal datasets, credentials, generated `node_modules`, or unverified performance claims.

New model adapters must expose all parameters used by the estimator and document stochastic behavior.
